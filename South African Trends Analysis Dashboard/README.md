# South Africa Trends Analysis Dashboard 2024

A comprehensive data visualization dashboard providing real-time insights into South Africa's key socio-economic indicators. Built with modern web technologies and featuring interactive data visualizations.

![Dashboard Preview](![image](https://github.com/user-attachments/assets/90394969-db67-424e-9d12-95eaa8dc7b34)
)

## 🌟 Live Demo

Visit the live dashboard: [South Africa Trends Analysis Dashboard](https://fanciful-griffin-bc5a6d.netlify.app)

## 🎯 Features

- **Interactive Trend Cards**
  - Real-time metric tracking
  - Historical data visualization
  - Detailed trend analysis with interactive charts
  - Key indicators: Unemployment, GDP, Inflation, Youth Employment

- **Provincial Analysis**
  - Comprehensive data for major provinces
  - Population and GDP statistics
  - Unemployment and poverty rates
  - Key issues and severity tracking

- **Demographic Insights**
  - Age-group based employment statistics
  - Interactive demographic charts
  - Economic activity distribution
  - Employment status breakdown

- **Economic Sector Analysis**
  - Sector-wise GDP contribution
  - Employment statistics by sector
  - Growth trends and analysis
  - Key sector performance indicators

## 📊 Data Sources

All data is sourced from official Statistics South Africa (Stats SA) reports:

- Quarterly Labour Force Survey (Q1 2024)
- GDP Statistical Release P0441
- Provincial Statistics Reports
- Sector Analysis Reports
- Youth Employment Statistics
- Consumer Price Index (CPI) Releases

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/sa-trends-analysis.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 💻 Development
